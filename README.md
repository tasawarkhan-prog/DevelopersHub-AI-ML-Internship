* [cite_start]**Skills Demonstrated:** Time series data handling, data fetching via `yfinance` API, and plotting actual vs. predicted prices[cite: 130, 138, 140, 141].

### [cite_start]3. Task 6: House Price Prediction [cite: 192]
* [cite_start]**Objective:** Predict house prices based on property features such as size, bedrooms, and location[cite: 194].
