# DevelopersHub AI/ML Engineering Internship

]This repository contains the projects and tasks I completed during my AI/ML Engineering Internship at DevelopersHub Corporation. The objective of these tasks is to build a strong foundation in machine learning, data preprocessing, model training, and evaluation using real-world datasets.

## Completed Tasks

### 1. Task 1: Exploring and Visualizing a Simple Dataset
* **Objective:** Load, inspect, and visualize the Iris Dataset to understand data trends and distributions.
* **Skills Demonstrated:** Data exploration with `pandas`, descriptive statistics, and visualization using `seaborn` and `matplotlib`.

### 2. Task 2: Predict Future Stock Prices (Short-Term) 
* **Objective:** Use historical stock market data to predict the next day's closing price using regression modeling.
* *Skills Demonstrated:** Time series data handling, data fetching via `yfinance` API, and plotting actual vs. predicted prices.

### 3. Task 6: House Price Prediction 
* **Objective:** Predict house prices based on property features such as size, bedrooms, and location[.
* **Skills Demonstrated:** Regression modeling, feature preprocessing, and model evaluation using metrics like Mean Absolute Error (MAE) and RMSE.
